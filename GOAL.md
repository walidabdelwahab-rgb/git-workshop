# Agent Goal Definition

## Primary Objective
The autonomous agent is assigned to inspect, evaluate, and optimize the student's portfolio page to ensure full alignment with academic requirements, structural clarity, professional presentation, and rigorous adherence to the course rubric standards.

## Scope of Work
- Review the current state of the portfolio layout.
- Compare content against the grading rubric specifications.
- Execute structured, incremental improvements without breaking core information or professional identification credentials.
